# AI Final Project Starter

This project is a starter template for an AI final project using supervised learning.

## Project idea

This starter uses classification with two methods:

- Logistic Regression
- Random Forest

It also uses built-in `scikit-learn` datasets so you can start testing immediately.

## Supported datasets

- `digits`
- `wine`
- `breast_cancer`

## Run the project

```bash
python3 src/train_baseline.py
